## 🎯 Tentang Repository

Repository ini dibuat untuk dokumentasi pembelajaran pemrograman web dasar, mencakup HTML, CSS, JavaScript, dan framework CSS modern seperti Tailwind CSS dan Bootstrap. 

Setiap folder pertemuan berisi:
- Materi pembelajaran
- Contoh kode
- Latihan praktik
- Dokumentasi (README.md)

---

## 📁 Struktur Folder

```
pemrograman-web-dasar/
├── pertemuan_1/       # Pengenalan HTML dasar
├── pertemuan_2/       # HTML lanjutan & Form

```

## 🛠️ Teknologi yang Digunakan

### Frontend Technologies
- **HTML5** - Struktur halaman web
- **CSS3** - Styling dan layout
- **JavaScript (ES6+)** - Interaktivitas dan logika

### CSS Frameworks
- **Tailwind CSS** - Utility-first CSS framework
- **Bootstrap 5** - Component-based CSS framework

### Tools & Resources
- **CDN** - Untuk load framework via internet
- **Git & GitHub** - Version control & repository hosting

## 🚀 Cara Menggunakan

### 1. Clone Repository

```bash
git clone https://github.com/Radhitndrm/pemrograman-web-dasar.git
cd pemrograman-web-dasar
```

### 2. Buka File HTML

Untuk melihat hasil pembelajaran, cukup buka file `.html` dengan browser: 

```bash
# Contoh: buka file di pertemuan_3
cd pertemuan_3
# Kemudian buka file . html dengan browser pilihan Anda
```
